## Ce que contient le fichier Figma

### Page « Styles & composants »
- **Styles de couleur** : palette Probeats (#292A2D, #009099, #41B4BB, #7EDCE1, #B6A299, #FFFFFF) + couleurs de support et de wireframe
- **Styles de texte** : police **Barlow** (Bold, Regular, Thin, Italique) — H1, H2, H3, corps, citation, prix, boutons…
- **Composants** : boutons, champ de formulaire, carte produit, carte « atout », emplacement d'image, 26 icônes, header et footer (desktop et mobile, versions maquette et wireframe)
- **Guide de style** : palette, échelle typographique, logo, favicon, grille

### Page « Écrans — Desktop & Mobile (prototype) »
Chaque page existe en **version desktop (1440 px)** et **version mobile (390 px)** :

| Page | Type | Contenu |
|---|---|---|
| Accueil | **Maquette** | Visuel pleine page, mise en avant du casque, ligne avec les deux enceintes, section « L'expérience Probeats », diaporama d'avis / extraits d'articles |
| Produit | Wireframe | Bloc produit (photo, nom, description, prix, bouton d'achat), bloc slogan + image d'ambiance, 3 caractéristiques en colonnes |
| Commande | Wireframe | Récapitulatif de la commande, informations de livraison et de paiement |
| À propos | Wireframe | Histoire de la marque, points forts de l'entreprise |
| Assistance | Wireframe | Services de l'entreprise, FAQ, formulaire de contact |

Plus un écran **menu burger ouvert** pour le mobile.

- Header commun : logo + menu (Produits, À propos, Assistance, Panier, Connexion)
- Footer commun : toutes les pages, mentions légales, contact, réseaux sociaux
- Grille : 12 colonnes / gouttière 24 px (desktop), 4 colonnes (mobile) — blocs de contenu avec padding de 24 px

## Prototype

Deux parcours sont configurés : **« Prototype Desktop »** et **« Prototype Mobile »** (bouton ▶ dans Figma).

Enchaînement principal : **Accueil → Produit → Commande**. Le menu du header, le logo, le panier et les liens du footer permettent d'aller sur toutes les pages. Sur mobile, le menu burger ouvre l'écran de navigation.
